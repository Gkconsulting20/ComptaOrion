---
name: Immobilisations en pause
description: Décision de garder temporairement le registre d’immobilisations désactivé dans l’ERP léger.
---

Garder le registre Immobilisations masqué et ses routes désactivées tant qu’il n’apporte pas une gestion complète des biens. Préserver les tables, données historiques et comptes SYSCOHADA de classe 2.

**Why:** l’utilisateur veut éviter d’alourdir le logiciel sans valeur ajoutée suffisante; le registre actuel ne gère pas les emplacements et ne génère pas les écritures d’acquisition, d’amortissement ou de cession.

**How to apply:** si le module est réactivé, vérifier le suivi par emplacement et les écritures comptables équilibrées; ne pas supprimer les comptes de classe 2 ni les données existantes lors d’une désactivation.
